# Cómo escribir notas

Las notas se escriben en **Markdown**: texto normal con unas pocas marcas.

| Escribes | Se ve |
|---|---|
| `# Título` | un título grande |
| `## Sección` | un subtítulo |
| `**negrita**` | **negrita** |
| `*cursiva*` | *cursiva* |
| `- elemento` | una lista |
| `- [ ] tarea` | una casilla para marcar |
| `[[Otra nota]]` | un enlace a otra nota |

## Buenas costumbres

- **Una idea por nota.** Notas cortas se enlazan mejor que un documento enorme.
- **Títulos que digan algo**: «Cómo funciona git rebase» en vez de «Apuntes 3».
- **Escribe con tus palabras.** Lo que copias se olvida; lo que explicas se queda.
- **Enlaza siempre que puedas**: mira [[Enlazar ideas]].
